# Student Registration & Contact Intelligence System

## Project Overview
This is a beginner-friendly Python command-line application for registering students and managing their contact information. Student details are stored in a CSV file.

## Features
- Add/register student details
- Display all registered students
- Search by student ID, name, email address or phone number
- Update student details
- Delete a student record
- Prevent duplicate student IDs and email addresses
- Save records automatically in `students.csv`

## Student Information Stored
- Student ID
- Full name
- Email address
- Phone number
- Course
- City
- Registration date and time

## Technology
- Python 3
- CSV file handling
- Python standard library only

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python app.py
   ```

5. Select an option from the menu.

The program creates `students.csv` automatically if it does not exist.

## Project Files
- `app.py` - Main Python program
- `students.csv` - Student data file
- `project_report.txt` - Project report
- `sample_output.txt` - Example program output
- `requirements.txt` - Dependencies
- `.gitignore` - Files Git should ignore
