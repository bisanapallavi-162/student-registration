PROJECT REPORT
STUDENT REGISTRATION & CONTACT INTELLIGENCE SYSTEM

1. INTRODUCTION
The Student Registration & Contact Intelligence System is a Python-based project designed to store and manage student registration and contact details. It provides a simple menu so that users can perform common record-management operations.

2. OBJECTIVES
- Register student information.
- Store contact details in an organized way.
- Search for records using ID, name, email or phone number.
- Update and delete student records.
- Save information for later use.

3. TECHNOLOGIES USED
- Python 3
- CSV (Comma-Separated Values) file
- Python standard library

4. MAIN MODULES
- Registration: accepts and saves a new student's details.
- View Records: displays all saved student records.
- Contact Search: searches by student ID, name, email or phone.
- Update: edits the details of an existing student.
- Delete: removes a selected student record.

5. DATA FIELDS
Student ID, name, email, phone, course, city and registration date/time.

6. CONCLUSION
This project demonstrates Python fundamentals including variables, functions, conditional statements, loops, input/output and file handling. It provides a basic system for maintaining student registration and contact records.
